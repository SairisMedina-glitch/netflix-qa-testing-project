# Plan de Pruebas - Netflix

## Objetivo
Validar el correcto funcionamiento de las principales funcionalidades de la plataforma Netflix, asegurando una experiencia de usuario adecuada.

## Alcance
Las pruebas se realizarán sobre las siguientes funcionalidades:

- Inicio de sesión (Login)
- Registro de usuario
- Búsqueda de contenido
- Reproducción de video

## Fuera de alcance
- Pruebas de rendimiento (performance)
- Pruebas de seguridad avanzadas
- Pruebas en dispositivos móviles

## Tipos de pruebas
Se ejecutarán los siguientes tipos de pruebas:

- Pruebas funcionales
- Pruebas de interfaz (UI)
- Pruebas de usabilidad

## Herramientas utilizadas

- Navegador web (Google Chrome)
- Excel (para casos de prueba)
- Capturas de pantalla (evidencias)

## Entorno de pruebas

- Sistema operativo: Windows
- Navegador: Chrome
- Sitio web: https://www.netflix.com

## Criterios de entrada

- Acceso a internet
- Navegador instalado
- Acceso a la página de Netflix

## Criterios de salida

- Todos los casos de prueba ejecutados
- Bugs documentados correctamente
- Evidencias recopiladas

## Riesgos

- Limitación de acceso a ciertas funciones sin cuenta activa
- Cambios en la interfaz de Netflix
